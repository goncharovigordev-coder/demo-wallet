# DemoWallet — учебный проект (Android, Java)

⚠️ **Это учебный демо-проект.** Приложение показывает вымышленные балансы
(USDT, BTC, ETH, USDC), которые пользователь может менять вручную прямо в
интерфейсе. Никаких реальных денег, блокчейнов, бирж или платежей внутри нет —
все данные хранятся только в оперативной памяти приложения и исчезают при
перезапуске. На каждом экране есть заметный баннер "ДЕМО".

## Что внутри

- `MainActivity` — список демо-активов и общий баланс.
- `AssetDetailActivity` — экран одного актива с полем для ручного ввода суммы.
- `AssetRepository` — простое in-memory хранилище (singleton) с 4 стартовыми активами.
- `Asset` / `AssetAdapter` — модель и адаптер для RecyclerView.
- Тёмная тема оформления в стиле реальных кошельков (фиолетовый акцент,
  карточки, крупные цифры), но с обязательными пометками "DEMO".

## Как собрать APK

1. Установите [Android Studio](https://developer.android.com/studio) (последняя версия).
2. Откройте эту папку через **File → Open** в Android Studio.
3. Дождитесь синхронизации Gradle (он сам скачает нужные версии Gradle/SDK,
   если у вас есть интернет — в моей среде сборки нет доступа в сеть, поэтому
   .apk я собрать не смог, только исходники).
4. Нажмите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Минимальные требования

- `minSdkVersion 24` (Android 7.0+)
- `compileSdkVersion 34`
- Java 8 совместимость

## Идеи для доработки (учебные задания)

- Добавить сохранение баланса между запусками через `SharedPreferences` или `Room`.
- Реализовать кнопку "Добавить актив" с диалогом ввода символа и названия.
- Добавить реальный список "истории операций" (тоже фейковый, для практики RecyclerView).
- Подключить публичный API курсов валют (например, CoinGecko) **только для
  отображения курса**, не более — чтобы не создавать иллюзию реального кошелька.

## Важно

Пожалуйста, не убирайте баннер "ДЕМО" и не выдавайте это приложение за
настоящий криптокошелёк — это может ввести людей в заблуждение и
использоваться для мошенничества.
